    The SQL gives the type as "enum('open','closed')" and the database reports "enum('Open','Closed')". dbDelta() lower-cases the type from the SQL but compares it with the database's type as reported, so values with capital letters never match.
    Fix: Use lower-case values in the ENUM or SET, or keep this column out of dbDelta().
  {prefix}acme_exists  [if-not-exists]

    Fix: Write CREATE TABLE without IF NOT EXISTS: dbDelta() already skips tables that exist.
